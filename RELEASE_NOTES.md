## Keystrike v0.3.0 - Ten new features

### Launcher
- **Custom hotkey** - Change the global shortcut in Settings → General (default stays Alt+Space).
- **App aliases** - Give any app a short alias, e.g. `ff` for Firefox, and it jumps to the top of the results.
- **Quick actions** - Type `lock`, `sleep`, `sign out`, `restart`, `shut down` or `empty recycle bin`. Destructive actions ask for a second Enter.
- **Window switcher** - Type `win` (or `win firefox`) to jump to any open window.
- **File search** - Type `file report` to search files and folders in Desktop, Documents, Downloads, Pictures, Videos and Music. Enter opens, Ctrl+Enter shows in Explorer.

### Productivity
- **Clipboard history** - Type `clip` to browse the last 50 things you copied. Kept in memory only, never saved to disk, and can be turned off.
- **Snippet search** - Type `snip` to browse and search your text snippets.
- **Currency conversion** - `100 usd to eur` with live exchange rates, cached for offline use.
- **Script commands** - Drop `.ps1`, `.py`, `.bat`, `.cmd` or `.exe` files into `%USERPROFILE%\.keystrike\scripts\` and run them from the search bar. Each printed line becomes a result.

### Appearance
- **Themes** - Light, Dark or System, plus accent colors, in Settings → General → Appearance.

All built-in keywords (`clip`, `snip`, `win`, `file`) can be renamed in Settings → Commands.
